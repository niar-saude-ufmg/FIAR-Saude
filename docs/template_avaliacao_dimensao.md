# Template de Avaliação por Dimensão

Este template é utilizado pelo NIAR-Saúde para consolidar a avaliação dos requisitos de uma dimensão do FIAR-Saúde.

A consolidação da dimensão não resulta de soma, média ou contagem mecânica de requisitos atendidos. Ela deve sintetizar os achados produzidos nos requisitos aplicáveis, considerando sua relevância, as limitações das evidências e o Contexto de Uso.

## 2. Síntese das evidências

Descrever as principais evidências utilizadas na avaliação da dimensão.

Considerar:

- tipos de evidência disponíveis;
- principais artefatos utilizados;
- limitações relevantes;
- complementaridade entre diferentes evidências;
- eventuais lacunas que afetem a interpretação da dimensão.

---

## 3. Síntese dos achados

Registrar os principais achados produzidos nos requisitos aplicáveis.

A síntese deve distinguir:

- achados favoráveis;
- limitações identificadas;
- problemas ou riscos identificados;
- questões ainda não resolvidas.

Evitar apenas repetir individualmente cada requisito. O objetivo desta seção é interpretar o conjunto de evidências da dimensão.

A existência de uma pendência não implica automaticamente resultado negativo para toda a dimensão.

Deve-se avaliar se a pendência:

- impede conclusão sobre um requisito específico;
- limita parcialmente a interpretação da dimensão;
- compromete uma questão crítica para o Contexto de Uso.
