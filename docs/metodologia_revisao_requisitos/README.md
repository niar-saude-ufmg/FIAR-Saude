
# Revisão metodológica dos requisitos do FIAR-Saúde

Esta pasta documenta o procedimento utilizado para revisar a fundamentação, clareza e usabilidade operacional dos requisitos canônicos do FIAR-Saúde.

A revisão é realizada separadamente para cada dimensão de IA Responsável:

- Governança
- Segurança
- Privacidade
- Responsabilização
- Rastreabilidade
- Justiça
- Transparência

O objetivo é assegurar que cada requisito:

1. possua fundamentação identificável em normas, recomendações, frameworks institucionais, regulamentações ou literatura científica;
2. represente um conceito próprio da dimensão em que está localizado;
3. seja formulado como uma exigência ou pergunta auditável;
4. tenha condição objetiva de aplicabilidade compreensível;
5. possa ser aplicado por um avaliador que não tenha participado da construção do FIAR-Saúde.

Os modelos de linguagem são utilizados apenas como instrumentos auxiliares de busca, organização e comparação textual. A fundamentação dos requisitos é estabelecida pelas fontes originais e deve ser verificável independentemente da saída do modelo.
